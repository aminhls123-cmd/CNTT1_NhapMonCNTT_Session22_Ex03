# Bài 3 : Sử dụng AI an toàn khi xử lý lỗi phần mềm

## Phân tích lỗi theo mô hình IPO
- Input: Câu trả lời của AI đưa ra câu lệnh lạ để sửa lỗi khi cài đặt Python.
- Process: Kiểm chứng bằng cách tra cứu trên Google hoặc trang chủ chính thức để xác thực.
- Output: Xác nhận lệnh an toàn hay không rồi mới quyết định thực thi.

## Câu lệnh hỏi ngược lại AI
- Hãy giải thích chi tiết từng thành phần của câu lệnh trên và phân tích tác động đến hệ thống máy tính của tôi trước khi thực hiện.
